# Session Checklist

Use this as the quick run sheet during a study session.

If anything here conflicts with the longer script, follow the longer script.

## Before The Participant Arrives

- GatorGoods frontend is running
- GatorGoods backend is running
- `SEED_FULL_RESET=true npm run seed:demo` has been run
- study/presenter account is signed in on GatorGoods
- searching `mini fridge` on GatorGoods shows 5 results
- Facebook Marketplace tab is open
- one Facebook `mini fridge` buyer listing has been chosen for this participant
- seller item photo and item details are ready
- Surveys 1, 2, and 3 are ready
- participant ID is assigned
- Order A or Order B is assigned

## Order Options

- Order A: Buy GatorGoods -> Buy Facebook -> Sell GatorGoods -> Sell Facebook
- Order B: Buy Facebook -> Buy GatorGoods -> Sell Facebook -> Sell GatorGoods

Try to use each order for about half of participants.

## Start Of Session

1. Read the opening from `Script.md`.
2. Confirm consent.
3. Give Survey 1.
4. Remind the participant to think aloud.
5. Remind the participant to assume they are a UF student living on or near campus.

## Buyer Block

1. Open the first buyer condition.
2. Start timing.
3. Let the participant complete the buyer tasks from `Tasks.md`.
4. Stop timing when they make their final buying decision.
5. Record notes.
6. Open the second buyer condition.
7. Repeat the same process.
8. Give Survey 2 after both buyer conditions are done.

## Seller Block

1. Open the first seller condition.
2. Start timing.
3. Let the participant complete the seller tasks from `Tasks.md`.
4. Stop timing when they make their final selling decision.
5. Record notes.
6. Open the second seller condition.
7. Repeat the same process.
8. Give Survey 3 after both seller conditions are done.

## Important Limits

- do not teach the interface
- do not compare the platforms for the participant
- do not require a real Facebook message to a stranger
- do not require waiting for replies
- for Facebook seller flow, stop before publish if you do not want to post a real listing

## Allowed Neutral Prompts

- What are you looking at right now?
- What do you expect to happen next?
- What information are you relying on here?
- What feels clear or unclear?
- If this were real, what would you do next?

## Notes To Record For Each Condition

- completed or not completed
- start time
- end time
- major confusion point
- strongest trust-related comment
- strongest campus-related or coordination-related comment
- final yes/no decision

## End Of Session

1. Ask the wrap-up questions from `Script.md`.
2. Thank the participant.
3. Save your notes immediately.
